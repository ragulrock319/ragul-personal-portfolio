# 🚀 Ragul E - Personal Portfolio Website

A modern, high-performance, and fully responsive personal portfolio website built with **React**, **Vite**, **Tailwind CSS**, **Framer Motion**, and **Lucide React**. Designed for a clean user experience, showcasing software development projects, technical skills, academic journey, and achievements.

![Portfolio Preview](/public/avatar.png)

---

## ✨ Features

- ⚡ **Lightning Fast & Lightweight**: Powered by Vite and React 18 for sub-second page loads.
- 🎨 **Modern Minimalist UI**: Clean design system featuring glassmorphism cards and deep slate/teal accent color palettes.
- 🌓 **Dark / Light Mode**: Seamless theme toggling with persisted user preferences in `localStorage` and system theme auto-detection.
- 📱 **Mobile-First Responsive Layout**: Optimized across desktop, tablet, and mobile viewports.
- ⌨️ **Animated Role Typewriter**: Interactive typing banner highlighting roles (*Software Developer Intern*, *Java Developer*, *Web Developer*).
- 📊 **Visual Skill Progress**: Animated progress bars with technical proficiency metrics across Java, Frontend, Node.js, MySQL, and DSA.
- 📁 **Project Showcase**: Card layouts with hover zoom effects, tech stack tags, feature highlights, and GitHub links.
- 🏆 **Achievements & Journey**: Dedicated sections for Hackathon awards, work experience, and B.Sc IT education timeline.
- 📬 **Validated Contact Form**: Client-side validation with instant visual feedback and copy-to-clipboard contact buttons.
- 📄 **Downloadable Resume**: Direct download link to a bundled PDF resume.
- 🔍 **SEO & Social Metadata**: Pre-configured OpenGraph metadata, Twitter cards, and custom developer SVG favicon.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) installed on your machine.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ragulrock319/portfolio-website.git
   cd portfolio-website
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
